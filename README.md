## 遊び方

### 起動

```vim
:source plugin/sengoku.vim   " または runtimepath に vim-sengoku を追加
:Sengoku                      " 新規ゲーム(大名選択)
:SengokuLoad                  " セーブデータから再開
```

プラグインとして使う場合は、このディレクトリごと `~/.vim/pack/games/start/`(Neovim なら `~/.local/share/nvim/site/pack/games/start/`)に置いてください。

dein.vim なら遅延読み込み(コマンド初回実行時にロード)がおすすめです:

```toml
# dein_lazy.toml
[[plugins]]
repo = '~/vim-sengoku'
on_cmd = ['Sengoku', 'SengokuLoad', 'SengokuTest', 'SengokuSiegeTest']
```

lazy.nvim の場合は `{ dir = "~/vim-sengoku", cmd = { "Sengoku", "SengokuLoad" } }` です。

推奨ウィンドウサイズ: **115桁 × 40行以上**(マップが110桁幅です)

画面情報は**マップに重なるポップアップ**で表示されます(Neovim のフローティングウィンドウ。Vim では枠付きパネルで代替):

- **勢力**: 各家の国数一覧をマップ左上の海域に重ねて常時表示
- **戦況**: 自家の行動結果(開発・徴兵・合戦など)や天下の出来事を画面下部に重ねて表示

どちらもウィンドウ幅・高さに自動追従するため、フォントサイズが大きくても必ず画面内に表示されます。

- **加賀の本願寺は民忠90**(百姓の持ちたる国)で一揆知らず

### 武将システム

- `1` 開発・`2` 商業・`3` 施し は担当武将の**政才**で効果が変わる。`5` 訓練は**戦才**
- `7` 出陣は**大将**を選ぶ。大将の戦才が全部隊の戦闘力に影響。守城側は在城武将の最強者が自動で指揮
- `9` 外交の使者は**政才**が成功率に影響
- `B` で自家の武将一覧(行動済みは「済」表示)。動ける武将が尽きたらその月は追加の仕事は頼めません
- 委任国は「直轄国の後に」残った武将で家臣が差配します。AI大名も同じ制約で動きます

### ルール

- 1ターン = 1ヶ月。自領それぞれに1コマンド → AI大名31家が行動 → 月末処理(商業収入、兵糧消費、9月に収穫、台風・一揆イベント)。
- **全41ヶ国を制圧すれば天下統一(勝利)。全領土を失えば滅亡(敗北)。**

### コマンド(領地ごとの月次プロンプト)

| キー | コマンド | 効果 |
|---|---|---|
| `1` | 開発 | 武将+金200 → 石高上昇(政才が影響)。収穫と徴兵上限の源 |
| `2` | 商業 | 武将+金200 → 商業上昇。商業値は毎月の金収入 |
| `3` | 施し | 武将+金100+米100 → 民忠上昇。民忠25未満は一揆の危険 |
| `4` | 徴兵 | 武将+金・米で兵を増強(上限は石高×20)。民忠と訓練度が下がる |
| `5` | 訓練 | 武将+金100 → 訓練度上昇(戦才が影響) |
| `6` | 鉄砲購入 | 金300 → 鉄砲20挺(文化度で増量)。武将不要 |
| `7` | 出陣 | **大将を選んで**隣接する敵領へ侵攻(籠城戦へ)。**同盟国へは出陣不可** |
| `8` | 輸送 | 隣接する自領へ金・米・兵を送る。武将不要 |
| `9` | 外交 | **使者を選んで**同盟の申し入れ(贈物 金500)/破棄/諸家の状況閲覧 |
| `C` | 朝廷 | 使者+金1000を献金して**官位**を賜る。官位持ちは**勅命和睦**(金2000)で確実に同盟締結 |
| `N` | 南蛮交易 | **南蛮港のある国のみ**。鉄砲の大量購入/**大筒**/南蛮の珍品(文化+5)。文化度で割引 |
| `T` | 茶会 | 金300。名物茶器が必要。全領土の民忠+文化度が上がる |
| `B` | 武将一覧 | 自家の武将と行動状況を確認 |
| `A` | 委任 | その国を家臣に任せる(残った武将でAIが差配)。マップに `*` 表示 |
| `R` | 委任解除 | 委任中の国を選んで直轄に戻す |
| `E` | 残り全国待機 | この月の残りの国をすべてスキップ |
| `i` | 情報 | 任意の国の詳細を閲覧 |
| `0` / 空白 | 待機 | 何もしない |
| `S` | セーブ | `~/.vim-sengoku-save.json` に保存 |
| `Q` | 降参 | ゲーム終了(確認あり) |

領地が増えてきたら後方の国は `A` 委任にして、前線だけ直轄するのが快適です。`Ctrl-C` で中断すると自動セーブされ、`:SengokuLoad` で再開できます。

### 朝廷と官位

- `C` 朝廷で使者を立てて**献金(金1000)**すると官位を賜れます: 従五位下 → 従四位下 → 従三位 → 参議 → 権大納言 → 内大臣 → **関白**
- 成功率は使者の政才・文化度で上昇、**山城(京)を領有していると+30%**。高位ほど叙任は難しくなります
- 叙任されると全領土の民忠+8、以後の外交成功率+3%/位
- 官位持ちは**勅命和睦(金2000)**で任意の家と確実に同盟を結べます(「勅命なれば是非もなし」)

### 南蛮交易と大筒

- 南蛮港は5つ: **堺(摂津)・博多(筑前)・府内(豊後)・平戸(肥前)・坊津(薩摩)**。港のある国でのみ `N` 南蛮交易が可能
- 品目: 鉄砲の大量購入(40挺+文化ボーナス)/**大筒**(金800)/南蛮の珍品(文化+5)。**文化度が高いほど割引**(最大50%)
- **大筒**は籠城戦の切り札: 城門・城壁への攻撃+40/門、斉射+25/門。ただし1門の運用に兵1500が必要(出陣兵数が少ないと持ち出せません)
- AI大名も港を持っていると鉄砲や大筒を買い込みます

### 茶器と文化度

- 名物茶器10点(九十九髪茄子・平蜘蛛釜・初花肩衝・新田肩衝・楢柴肩衝・三日月茶壷・松島の壷・珠光小茄子・曜変天目・青磁千声)が乱世に眠っています
- **堺の商人**がときどき名物を売りに来ます(金は最も裕福な自国から支払い)。AI大名も買い集めます
- 初期所持: 松永家(九十九髪茄子・平蜘蛛釜)、三好家(三日月茶壷)、今川家(松島の壷)
- **文化度**の効果: 商業収入ボーナス(+文化%)、鉄砲購入数アップ、外交成功率アップ。茶器入手と茶会で上昇
- **大名家を滅ぼすとその家の茶器をすべて接収**できます(茶器狩り)

### 外交

- `9` 外交から**同盟**を申し入れられます(贈物 金500)。成功率 = 25 + 魅力/3 + 文化/5 + 茶器×4(最大90%)
- 同盟中は互いに攻撃できません。破棄はいつでも可能ですが信義を失い文化-3
- AI大名同士も同盟を結び、勢力図に影響します。AIから同盟の申し出が来ることもあります
- 大名家が滅亡するとその家の同盟はすべて消滅します

### 合戦のしくみ — 籠城戦(攻城戦マップ)

プレイヤーが関わる合戦は、**画面が切り替わって攻城戦マップでの籠城戦**になります(出陣時・攻められた時とも「采配を振るいますか?」で選択。n を選ぶと従来の自動解決)。

```
■ 三河城 攻防戦   3日目/30日
攻手:織田軍 兵4000★  守手:松平軍 兵4200

  ・・・・・・・・・・・・
  ・・・森・・・・・・・・    攻１ 兵800 砲12←   守甲 兵840 砲2
  ・・・・・・壁壁壁壁壁・    攻２ 兵800 砲12    守乙 兵840 砲2
  ・・森・・２壁甲・・壁・    攻３ 兵800 砲12    守丙 兵840 砲2
  １・・・・・門・・本壁・    攻４ 兵800 砲12    守丁 兵840 砲2
  ・・・・森５壁・・丁壁・    攻５ 兵800 砲12    守戊 兵840 砲2
  ・・・・・３壁壁壁壁壁・
```

- 兵力は**最大5部隊**に分かれます(攻手:１〜５、守手:甲〜戊)。1ターン=1日、**30日以内**に決着
- 各部隊は毎日 `hjkl`(または矢印キー)で**移動3歩**、`a` で隣接攻撃、`f` で鉄砲斉射(射程2)、`w` で待機
- **城門(耐久120)・城壁(耐久200)** は攻め手が攻撃して打ち破れます。門は守手だけが通行可能(打って出る「城外出撃」も可)
- **攻め手の勝利条件: 本丸(本)を占拠する** か守兵を全滅させる。**守手は30日守り切れば勝ち**
- 森は被害-20%、城内の守手は-30%の地の利。鉄砲隊は撃ち合いの要
- `Q` で攻め手は全軍退却(残兵帰還)、守手は開城(城を明け渡す)
- AI同士の合戦、および委任中の国の合戦は従来どおり自動解決(守備側2割ボーナス、兵1/4で撤退)
- 相手の最後の城を落とすとその家は滅亡(茶器接収!)

`:SengokuSiegeTest` でAI同士の籠城戦シミュレーションを確認できます。

### 攻略のヒント

- 最初の1年は内政(開発・商業・訓練)。攻めるなら**相手の1.5〜2倍の兵+鉄砲**を用意
- 兵は毎月「兵数÷50」の米を食べます。9月の収穫まで兵糧がもつか常に確認を
- 31家がひしめくので、AI同士の潰し合いで消耗した国を狙うのが定石
- 奪った直後の国は民忠が低い → `3` 施しで一揆を防止
- 弱小大名(赤松・河野・波多野など)でのプレイは高難度でやり込み向け
